# Official FPGA design root

This directory is the sole future location for authored FPGA RTL, constraints,
IP configuration, simulations, and source-driven Vivado Tcl.

No generated Vivado project, run directory, checkpoint, bitstream, or Hardware
Manager output is authoritative source. Such outputs are created under the
active bring-up unit only when a stage is authorized.

No FPGA source has been created during the preparation phase.
